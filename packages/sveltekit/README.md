# @spatial-elements/sveltekit

SvelteKit components for interactive 3D collections and detail pages, built on the shared Page Sections layout system.

- Compose BrandStageShell, SpatialCardGridSection, SpatialCarouselSection and SpatialElementPage.
- Keep the renderer alive across related routes while using native links and SvelteKit navigation.
- Combine spatial content with Page Sections, sidebars, headings and responsive grids.
- Supply poster images for meaningful SSR and no-WebGPU fallbacks.
- Adapt themes and interface texts to your application.

## Installation

```sh
npm install @spatial-elements/sveltekit@beta three@^0.186.1
```

Requires Node >=22.12 for tooling, Svelte ^5.56.4 and SvelteKit ^2.70.3. This is a beta package. Models and environments belong to your application and are not bundled.
