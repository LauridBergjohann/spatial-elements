# Minimal Spatial Elements demo

One BrandStageShell, a collection with one model, and its detail page. Start with src/lib/starter.ts and the routes under src/routes/starter. Run npm run dev:demo from the repository root. There is no documentation navigation or test instrumentation in this application.
