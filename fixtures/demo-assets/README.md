# Original demo assets

The column, orb and ring are procedural primitives generated by tooling/asset-pipeline/generate-demo.mjs.
Both LODs use the same coordinates and material. Posters are original SVG illustrations;
the studio environment is an original constant-color Radiance HDR. No third-party models,
logos, photographs or brand data are used. These assets and their generator are MPL-2.0.
Regenerate with npm run assets:demo. Shared files are copied into demo static directories
by scripts/sync-demo-assets.mjs; they are not included in the runtime npm packages.
