# Changelog

## 0.1.0-beta.1

First public beta, published to npm.

Subsequent release notes are maintained by Changesets in each package's CHANGELOG.md.

- Framework-independent Three.js/WebGPU runtime in `@spatial-elements/core`.
- SvelteKit content pages, list and carousel sections, and spatial element detail pages.
- Prepared navigation, shared-element transitions, history and scroll restoration.
- Progressive geometry loading, interaction, minimap and themed panels.
- Semantic HTML and poster fallbacks when GPU rendering is unavailable.
- Original procedural demo assets; no private brand assets are distributed.
- Consistent SpatialElement API terminology across packages.

Requires Svelte 5, SvelteKit 2 and Three.js 0.185 within the declared peer ranges.
APIs may change during beta. Vue/React adapters are not included.
